# KAZIND 3D Web Trainer — Updated

## Included
- Mandatory first-launch tutorial and controls orientation
- Open-source India defence-context briefing with links to public reporting
- First-person 3D training compound with perimeter fencing, buildings, containers, barriers, watchtower, floodlights, vegetation, mountain backdrop, and static armoured-vehicle props
- E locks a tracked target and keeps it locked during the simulated scan; a visual ring indicates the lock
- Seven progressive levels, including swarm/night operations, mountain-sector observation, and integrated exercise scenarios
- Classification, scoring, progress unlocks, and after-action review

## Run locally
Internet is required to load Three.js from jsDelivr.

```bash
python -m http.server 8000
```
Open http://localhost:8000 in a WebGL-enabled browser.

## Controls
- WASD / arrow keys: move
- Shift: sprint
- Click the scene: capture mouse
- Mouse: look around
- E: lock target and start scan once tracking completes
- J: classify as Commercial-style
- K: classify as Military-style
- Esc or P: pause

## Notes
The defence briefing links to public reporting and is a high-level educational summary, not official advice or endorsement. Armoured vehicles are static scene props. All drone profiles and actions are fictional game mechanics. The game does not connect to real drones, sensors, radio systems, or weapons.
